Getting Started

Choose your path: AI integration or manual search

For AI Integration (Claude Desktop)

  1. Clone the repository: git clone https://github.com/saurabhgayali/JobSearchMCP.git
  2. Install dependencies: npm install && npm run build
  3. Edit ~/.claude/claude_desktop_config.json:
{
  "mcpServers": {
    "job-search": {
      "command": "node",
      "args": ["path/to/dist/server.js"]
    }
  }
}
  • Restart Claude Desktop and ask: "Find manager jobs at Amgen"

    • For Manual Web Search

    1. Deploy to Vercel: vercel deploy
    2. Visit: https://your-app.vercel.app/
    3. Enter search term, select companies, browse results
    4. Download as CSV

    For Local Testing

    npm run build
    node dist/test/test-manager-jobs.js

    How It Works

    Same extraction engine, different interfaces

    Architecture Overview

    Component AI Path Manual Path
    Interface Claude/ChatGPT Chat Web Browser
    Server MCP Server (src/server.ts) Next.js API (app/api/)
    Logic Shared: SearchExecutor + Extractors
    Output Markdown Response JSON → React UI
    Reports AI Summarizes CSV Download

    Job Extraction Process

    1. Search Job Listings
    Fetch URLs from each company's career site based on search term

    2. Extract Job Details
    Parse HTML using company-specific regex patterns (Workday, Eightfold AI, Drupal)

    3. Track Errors Intelligently
    Classify failures: 404 (not found), timeout, network error, parse error

    4. Return Structured Data
    JSON with job title, description, requirements, expiry date, apply link

    5. Optional CSV Report
    Generate downloadable CSV for successful & failed extractions
    ✓ No AI Required: The job extraction works completely without any LLM or machine learning. AI integration is optional and only enhances the user experience by allowing natural language queries.
