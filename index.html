What is Job Search MCP?

A Model Context Protocol (MCP) server that enables AI assistants to search and extract job listings from company career websites. Unlike traditional web scrapers, this is a configuration-driven system where new companies can be added without modifying code.

Current Coverage:

Amgen (Workday) Bayer (Eightfold AI) GSK (Workday) Novartis (Drupal) Pfizer (Workday)

Key Features

🤖 MCP Compatible

Works with Claude Desktop, Cursor, and any MCP-compatible AI client

⚙️ Configuration-Driven

Add companies via JSON config - no code changes needed

📊 Smart Parsing

Regex-based extraction (no heavy dependencies like Puppeteer)

🛡️ Error Tracking

Classify errors: 404s, timeouts, network issues, parse errors

📈 Extensible

Designed for 250+ companies - platform-agnostic extractors

📋 CSV Reports

Generate batch reports for successful and failed extractions

Quick Start

1. Installation

npm install
npm run build

2. Run MCP Server

npm start

3. Configure in Claude Desktop

Edit ~/.claude/claude_desktop_config.json:

{
  "mcpServers": {
    "job-search": {
      "command": "node",
      "args": ["path/to/dist/server.js"]
    }
  }
}

4. Use in Claude

Just ask: "Find me senior manager jobs at Amgen and Pfizer"

Adding Companies

The system is designed to scale to 250+ companies with minimal effort:

Step 1: Add Configuration

Edit src/config.json:

"sites": [
  {
    "name": "NewCompany",
    "search_url": "https://careers.newcompany.com/search?q={SEARCH_TERM}"
  }
]

Step 2: Create Site Definition

Add sites/newcompany.json with search parameters (see sample in test/sample.json)

Step 3: Add Extractor (if new platform)

Create src/extractors/newcompany.ts with HTML parsing rules

Step 4: Register Extractor

Update src/extractors/index.ts to include new company

💡 Tip: If the company uses an existing platform (Workday, Eightfold AI, Drupal), you can reuse the existing extractor - only config changes needed!
