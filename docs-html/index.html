Setup Guide

System Requirements

Requirement Version
Node.js v24.19+ (LTS)
npm v10.0.0 or higher
Memory 512 MB minimum
Disk Space 500 MB for dependencies

Installation Steps

1. Clone Repository

git clone https://github.com/saurabhgayali/JobSearchMCP.git
cd JobSearchMCP

2. Install Dependencies

npm install

3. Build TypeScript

npm run build

4. Verify Installation

node dist/test/test-config.js
✓ Success: You should see a list of supported companies (Amgen, Bayer, GSK, Novartis, Pfizer)

Troubleshooting

Node.js Version Issue

Verify you have Node v24.19+:

node --version

If not, install via nvm:

nvm install 24.19
nvm use 24.19

Module Not Found

Rebuild dependencies and clear cache:

rm -rf node_modules package-lock.json
npm install
npm run build

Build Errors

Ensure TypeScript compiles:

npm run build

Should complete with no output (clean compilation).

  2. Create Lambda Function: Upload ZIP from dist/
  3. API Gateway: Create REST API, map routes

Rate Limiting Configuration

Overview

Protects backend from abuse. Default: 5 searches per 24 hours per IP

How It Works

  1. Extract client IP from X-Forwarded-For or X-Real-IP headers
  2. Check if IP has exceeded limit in current window
  3. If limit exceeded, return HTTP 429
  4. If within limit, increment counter and proceed

Configuration

Edit app/api/search-jobs/route.ts:

const RATE_LIMIT_MAX_REQUESTS = 5;        // 5 searches
const RATE_LIMIT_WINDOW = 24 * 60 * 60 * 1000;  // 24 hours

Development Mode

In-memory storage (resets on server restart)

const requestCounts: { [key: string]: { count: number; resetTime: number } } = {};

Production Mode

Use Redis (ElastiCache on AWS or Heroku Redis):

const redis = new Redis(process.env.REDIS_URL);
await redis.incr(`rate-limit:${clientIp}`);
await redis.expire(`rate-limit:${clientIp}`, RATE_LIMIT_WINDOW / 1000);

Response When Rate Limited

HTTP 429 Too Many Requests

{
  "error": "Rate limit exceeded. Maximum 5 searches per 24 hours per IP. Try again in 18 hours."
}

Testing Rate Limits

for i in {1..6}; do
  curl -X POST http://localhost:3000/api/search-jobs \
    -H "Content-Type: application/json" \
    -d '{"query":"Manager","companies":["amgen"]}' \
    -H "X-Forwarded-For: 192.168.1.1"
  echo "Request $i"
done

6th request should return 429
